# 全站 UI 审查（第四轮）：剧本整理、主持顶栏、打印、统计、设置、角色文案

日期：2026-09-25。只调整排版、交互与文案，不改游戏规则、数据格式或存储。

## 剧本页：文件与标签管理

| 观察到的问题 | 影响 | 调整 |
| --- | --- | --- |
| 文件夹、标签筛选是两个上下堆叠的自动完成框，排序与「管理文件夹」又占一行 | 侧栏首屏被筛选占满 | 排序 + 文件夹下拉（含「未分类」）+ 管理按钮同一行；标签改为可点选的筛选 chip |
| 每行「…」常显，一列相同图标 | 列表视觉噪声大 | 鼠标设备悬停或键盘聚焦时显示，触屏常显；当前剧本行始终显示 |
| 列表看不出剧本在哪个文件夹 | 整理后难以核对 | 行副标题追加文件夹名 |
| 「标签与备注」面板约 330px 高，含三段说明文字 | 打开后正文被推到首屏外 | 改为「整理」面板：文件夹 / 标签 / 备注三行，约 150px |
| 文件夹管理：新建分两行，改名要再开一个弹窗 | 操作路径长 | 单行新建（名称 · 来源 · 添加）、行内改名、显示每个文件夹的剧本数 |
| 卡片视图搜索框浮动标签被圆角裁切 | 标签看不清 | 回到图标 + 占位符 |

## 主持页顶栏

| 观察到的问题 | 调整 |
| --- | --- |
| 「打开观众窗口」独占一行（桌面和手机都是） | 移入右侧栏（手机为 ☰ 抽屉）「投屏」；展示期间才在竞技场上方显示一条状态条（私密视图、定位、结束） |
| 桌面端顶栏的新游戏 / 分配 / 保存与右侧栏重复 | md 及以上只保留右侧栏；以下（无常驻侧栏）仍在顶栏 |
| 桌面端「≡<」按钮无任何作用（右侧栏常驻） | md 及以上移除 |
| 音乐控件拉伸成一条横贯整行的长胶囊 | 按内容宽度显示 |
| 「7T0O2M1D」对中文用户难懂 | 显示「7镇0外2爪1恶」，悬停显示完整阵营名 |
| 语言下拉占位宽 | 紧凑的语言按钮，显示当前语言（中文 / EN），提示中写明点击切换到哪种语言；打印、统计同样使用 |

结果：统计、剧本、音乐、撤销、语言压成一行，桌面竞技场高出约 80px。

## 打印

- 两个打印页共用顶栏：返回 · 「标记 / 剧本单」切换 · 剧本 · 语言 · 反馈 · 设置面板 · 导出。剧本单现在也能切回标记。
- 剧本单设置从 9 个带边框折叠块合并为 4 组（输出与纸张、布局、字体、图标与夜晚顺序），组间用分隔线。
- 标记设置：背景与边框合并；阵营筛选改 chip；「全部」按钮改名「全选」，避免与阵营筛选的「全部」同名；角色列表修复为单列滚动（原先 FormGroup 默认换行，被 maxHeight 挤成被裁切的多列）；搜索框不再同时显示标签和占位符。
- 滑块刻度标签不再压到下一行（`sx.mb: 0` 覆盖了 MUI 为刻度标签预留的下边距）。
- 未选角色时，预览区显示居中的空状态与提示；页码说明已翻译。

## 统计

- 标题与导入 / 导出 / 分享同一行；手机上刷新和语言固定在标题右侧，操作按钮换到下一行。
- 无记录时隐藏筛选条和初始 / 最终身份切换，概览给出「新建记录」按钮；身份口径的长说明收进 ⓘ 提示。
- 概览数字卡片在宽屏一行排下；手机上奇数张时最后一张占满一行。
- 筛选条控件高度与标签统一，胜方写作「说书人」（不再是「ST」或「说书人:」）。

## 设置

- 每项设置一行：左侧名称与说明，右侧控件（手机上下堆叠），页面高度约减少 30%。
- 内置 Google 登录的网页版不再显示 redirect URI 配置框和「凭据已内置」提示；仅在需要自带 OAuth 客户端时显示。
- 同步与备份说明改为「剧本」（不是「脚本」），并如实列出内容：文件夹、标签和备注，用户添加的能力修订；同步另含游戏记录。

## 角色页文案与筛选

- 能力修订统一译为「修订」（当前修订、修订历史、添加修订），「版本」只指 edition；已写入 `terminology.json`。
- 「首夜 / 其他夜晚」统一；字段名去掉 ZH/EN（中文名称（可选）、能力文本（中文，可选））；全角冒号；英文徽标不再全大写。
- 剧本筛选与「更多筛选」同一行；展开面板集中放版本（官方按发行顺序在前，民间在后）与剧本候选范围。
- 修订备注为空时不再显示「备注 -」。
