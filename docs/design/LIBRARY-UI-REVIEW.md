# 剧本与角色页面：第二轮 UI 审查

日期：2026-09-22。本轮仅调整界面，不推进 API 设计或实现。

## 痛点与实施方案

| 观察到的问题 | 对用户的影响 | 本轮调整 |
| --- | --- | --- |
| 新建、导入在剧本页顶部和侧栏重复出现 | 难判断是否存在不同作用范围，工具栏拥挤 | 库级新建、导入各保留一个入口；卡片分组里的重复新建也移除 |
| 导出与全库操作放在一起 | 容易误以为导出整个剧本库 | 导出 / 分享移到当前剧本操作区，导出对话框继续明确显示剧本名 |
| 卡片视图、单双栏、隐藏能力、夜序都是小图标 | 需要逐个试探，低频功能占据主操作区 | 卡片视图、正文排版、能力显示、语言集中到有文字标签的“显示设置” |
| 夜序默认展开，首屏几乎看不到剧本正文 | 浏览剧本变成先滚过一整屏夜序 | 默认折叠夜序，仅保留夜序面板自身的展开入口；屏幕阅读时相克与附加规则移至角色列表之后 |
| 未选标签、添加备注和自定义标签输入框常驻 | 无需整理元数据时仍被大量弱按钮干扰 | 收入“标签与备注”，按钮显示已有标签数量和备注存在标记 |
| 手机上展开列表后，详情继续排在列表下方 | 需要滚动寻找详情，选择是否生效不明显 | 列表与详情交替显示；选择后自动回到详情，明确的“选择剧本”按钮用于返回 |
| 角色页来源、文件夹和长帮助常驻 | 首屏被过滤器占据 | 剧本多选保留，来源与文件夹收进“更多筛选”，帮助文字缩短 |
| 版本筛选和导入 / 导出 / 相克 / 夜序混在一个折叠区 | 查找与管理两种任务混淆 | “更多筛选”管理版本和剧本候选范围；“角色工具”独立对话框管理导入、角色包、规则和语言 |
| 单个角色导入只有一个上传图标 | 无法判断与角色包导入的差异 | 用文字区分“导入单个角色”和“角色包管理”，附作用说明 |
| 筛选为空仍显示禁用清空按钮；无结果时又出现第二个清空 | 无效或重复按钮制造视觉噪声 | 仅在存在条件时显示一个清空入口；收起版本筛选后仍显示可移除的已选版本 |

## 保留的使用路径

- 剧本：列表搜索 → 选中剧本 → 阅读 → 编辑或导出。库级操作与当前剧本操作分开。
- 角色：关键词 / 类型 / 剧本 → 结果 → 查看详情。工具管理不占据筛选区。
- 卡片视图仍可通过显示设置进入，避免删除已有使用方式；默认保持列表。
- 批量导入预览、同名副本、文件夹整理、多选剧本、JSON / PDF / 分享继续可用。

## 后续可观察的问题

- 用真实使用反馈决定是否保留独立卡片视图，而不是仅凭低频直接删除。
- 剧本很多时，文件夹与标签筛选仍可能拥挤；下一轮可集中成筛选面板。
- 角色详情里的完整修订历史占用较多空间，可单独评估“当前能力优先、历史按需展开”，本轮不改修订编辑行为。
- 不调整全站字体、配色和顶层导航，保持这两页与现有界面一致。

验证：桌面 / 手机端批量导入、重复副本、JSON 导出、多剧本与角色类型组合筛选；显示设置切换列表 / 卡片；角色工具与候选范围展开；无横向溢出。另运行 TypeScript、构建和中英文文案检查。

## 剧本导航细化（第三轮）

根据侧栏截图进一步精简：移除重复“剧本（数量）”标题；以“全部 / 官方 / 社区 / 我的”筛选替代三个展开分组。计数随搜索、文件夹和标签条件更新，排序显示当前文字选项并作用于完整结果集。

每行固定为名称和“作者（缺省时为来源）· 角色数 · 可选版本”；选中状态使用浅底、左侧线和勾选标记。复制、移动、删除统一收到行尾菜单，内置剧本不显示删除，复制后切换到“我的”。

文件夹不再形成多层滚动树：可搜索的文件夹筛选负责定位，“管理”负责新建、改名、删除；删除文件夹保留其中剧本。列表限定视口高度，仅结果区滚动。筛选隐藏当前剧本时提供“显示当前剧本”入口；“我的”为空时才展示新建引导。
